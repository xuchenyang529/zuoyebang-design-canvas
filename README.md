# 作业帮 · 智能设计画布

[打开可交互原型](https://xuchenyang529.github.io/zuoyebang-design-canvas/)

面向 B 端设计师的桌面 Web 演示原型。无需登录，可直接分享链接。

## 体验路径

1. 查看预置的 9 张学习机、学习场景、参考海报与品牌素材。
2. 对 Agent 输入「用这些图帮我做一张新品海报」，查看和调整最多 6 张引用。
3. 发起生成，查看画布与对话同步的任务状态。
4. 在结果上点击「继续修改」，输入「标题再醒目一点，产品和背景尽量保持」。
5. 查看新版本并对比结果；演示控制台可模拟超时和失败恢复。

这是前端交互演示，生成和 Agent 行为使用模拟数据。状态仅保存在各访问者自己的浏览器中。

`index.html` 内含样式、脚本和演示图片，也可下载后直接本地打开。
