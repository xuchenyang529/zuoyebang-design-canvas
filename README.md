# 作业帮 · 智能设计画布

[打开可交互原型](https://xuchenyang529.github.io/zuoyebang-design-canvas/?v=library4)

面向 B 端设计师的桌面 Web 演示原型，无需登录。

## 体验路径

1. 在产品图、模特图、风格参考、品牌标识等分类中独立批量上传图片。9 张原示例为可选载入，不限定素材数量。
2. 勾选素材，单独或批量打标，例如产品白底图、模特图。
3. 用勾选素材发起海报创作，每次最多引用 6 张。
4. 换一组素材再次生成，已有结果同时保留，可分别标为采用或暂不采用。
5. 对任意结果点击继续修改，输入修改意见，新增版本并保留来源。

这是前端交互演示，使用实际勾选图片模拟排版，未接入真实生成模型。素材与结果保存在访问者自己的浏览器中，容量受浏览器本地存储限制；单张上传上限为 8MB。

部署采用静态入口、交互脚本及已有示例资源包；无需服务端。
